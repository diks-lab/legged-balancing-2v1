# 傾いた起動姿勢からの起立待ち

基準先頭05188d5、codex/2208-web-ps4、PR #13。
**正常初期化後も0°±2°の範囲外では車輪ENを遮断し、起立待ちにする。**
機体を後方から持ち上げ、有効な最新姿勢が範囲へ入った最初の制御周期で倒立を開始する。
完全一致0°・静止保持時間・準備時間・u／t等のボタン操作は要求しない。
角速度・車輪速度にも静止待ちの閾値を設けない。有限性は確認する。

## 初期化と開始

保存済みFOC校正の復元、IMU校正、両輪センサー・FOC・既存Web等の必須初期化は維持。
有効保存値がなければ要校正で停止し、起動時に勝手な校正走査を行わない。
校正・保存後に停止を維持する明示校正の仕様と、NVS形式も変更しない。

MPU6050_tocknのbeginは加速度由来の測定角を初期値にする。
これは姿勢推定の初期化であり、制御目標角の取得ではない。
calcGyroOffsetsは既存のジャイロ校正だけ。**傾いた起動姿勢を目標として登録しない。**
傾いた状態で電源投入できるが、IMU校正中はその姿勢で静止させる従来の前提は必要。
校正・初期化が終わって「起立待ち」となるまで保持し、その後に機体後方を持ち上げる。

起立待ち中は通常ループでIMU・車輪を更新し、姿勢を常時監視する。
ENを遮断し左右指令を0に保つ。ボタン操作なしで、最新有効姿勢の±2°進入周期に
既存の開始リセットを実行する。目標0°を設定し、**その時点**の車輪位置を原点にしてENを有効化。
初期化時／傾いて待っていた時の車輪位置を開始原点として固定しない。
待機中のWebでも、姿勢と固定の基準角0°を表示する。

IMUの有効性・直近読取り成功・250 ms以内の鮮度、両輪センサー正常、
保存校正・FOC readyを、転倒復帰と同じ条件関数で確認する。
無効測定・センサー／FOC異常・明示停止は自動開始意図を解除。
姿勢を戻したり正常状態へ戻っただけでは再始動しない。
既存のPS4操作・手動診断開始経路は今回変更しない。

## 転倒復帰・表示

転倒後も同じ±2°への進入周期で即時復帰する。保持時間・低角速度／速度待ちはない。
復帰時も目標0°、位置原点は復帰時に取得。
既存の転倒・異常停止閾値／連続確認時間、出力限度は変更しない。
右−1／左＋1、PID、FOC設定、制御フィルター、初期モードATTITUDE_ONLYは維持。

Web上部の同じ#healthに「起立待ち」「倒立中」「転倒復帰待ち」を表示。
直立範囲・IMU・車輪センサー・FOCの固定4条件と○／×／？、下部詳細は維持。
待機中の姿勢と遮断表示、通信／測定停止時の不明表示も維持する。

## 検証

ホストの実制御関数で、初期化／校正未完了は開始しないことを確認。
初期化後15°のまま複数周期待ってもENが両輪ともLOW・未開始、姿勢15°・基準0°・
起立待ちを配信。1.9°に入った周期で、時間を進めず開始しENが有効になる。
角速度3 deg/s・車輪速度1 rad/sでも静止待ちしない。
待機中に位置が4.25→6.25 radへ動いた場合、開始位置原点が6.25 radとなることを確認。
待機中の明示停止・IMU異常・FOC異常後は範囲へ戻しても再始動しない。
転倒復帰・範囲通過・再転倒・PS4停止等の既存回帰、制御ASan/UBSanも実施。

実Chromium＋模擬JSONで起立待ち・姿勢更新・遮断・固定位置の状態表示、
1366×768／1920×1080・100%でのスクロール不要、既存グラフ／条件表示を確認。
実機の傾いた状態での校正・起立待ち・持ち上げ開始・姿勢復帰・停止・Wi-Fi／PS4併用は未検証。
強い振動は未解決で、今回の変更で改善したとは扱わない。
ジャンプ着地・接地検出・空中制御は対象外で、別途検証が必要。

## 更新・確認手順

**今回はファームとLittleFSの両方を更新する。** 校正NVSは通常の書込みで維持される。

```sh
pio run -e esp32dev
pio run -e esp32dev -t buildfs
# 利用者が保持・対象ポートを確認して実施。エージェントは未実施。
pio run -e esp32dev -t upload --upload-port PORT
pio run -e esp32dev -t uploadfs --upload-port PORT
```

傾いた状態で機体を確実に保持して電源投入し、IMU校正中は動かさない。
正常初期化後、範囲外では起立待ち・遮断のまま姿勢が更新されることを確認する。
機体後方を持ち上げて±2°へ入れると、保持待ちなしで両輪が駆動し得る。
中止はPS4×／USB d。明示停止後は姿勢を戻しても開始しないことを確認する。
保存値がない場合は先にWebから明示校正し、保存完了・停止を確認してから再起動する。
ビルド／ホスト／模擬ブラウザー成功を実機成功とは扱わない。マージ・実機書込みなし。

ESP32ビルド・LittleFS生成成功。静的RAM81,276 Bで増減なし。
