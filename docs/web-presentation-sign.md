# 姿勢角とドーナツの表示規則

245f4e6を基準とする表示のみの変更。
姿勢角の現在値・直立範囲ラベル・±30°範囲外の実角度は小数1桁。
丸め後の負のゼロは0.0°と表示する。詳細診断には元の姿勢角を残す。
判定・記録・配信の精度、グラフの座標値は変更しない。
後部接地姿勢約−48.9°は実傾斜であり、0°へ補正しない。
姿勢グラフの±30°固定・超過方向マーカーを維持する。

左ドーナツだけ実指令×−1で数値・円弧方向・色を統一する。右は実指令のまま。
補助グラフ・CSV・WebSocket元データ・モーター出力は元符号。
ゼロ・遮断・更新停止／不明・上限超過の扱いを維持する。

## 検証

ホスト試験で小数1桁、負のゼロ、正負・ゼロ・上限超過、元データ非変更、
右の符号維持、遮断・無効値・通信停止、履歴・CSV・購読・直列取得を確認。
実Chromium＋模擬WebSocketで1366×768／1920×1080（100％）を確認。
姿勢範囲外、詳細の元精度、2.01°が表示2.0°でも直立判定×を維持すること、
左右数値／円弧、表示一時停止、切断・再接続を確認。
LF／CRLFとも各ファイル8192 B以内。ソースの改行・インデントは維持。
ESP32ビルド・LittleFS生成成功。ファームRAM 81,540 B／Flash 1,913,029 Bは不変。
実機試験は未実施。前進が止まらない症状や強い振動の対策ではない。

## 書込み

更新対象はLittleFSのみ。245f4e6以降のファームなら通常ファームの再書込み不要。

```sh
pio run -e esp32dev -t buildfs
pio run -e esp32dev -t uploadfs
```

実機書込みは利用者が停止・安全を確保して実施する。本作業では書込み・マージを行わない。
書込み後はページを再読込みし、約−48.9°の範囲外表示、左の表示反転、
詳細／補助グラフの元符号、遮断・配信停止の表示を確認する。
PID・DLPF・保存FOC・FULL・起立／復帰・停止条件は変更しない。
