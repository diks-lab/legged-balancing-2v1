# 2208 短距離走行試験（実機未検証）

基準はPR #11の `c4ba29b985c9c0b444231ea4c280fd3badf91e90`。
親ブランチ `codex/attitude-only-2208` は変更しない。
ユーザーの実機確認では、親版のAttitudeOnlyで約71秒、手の支えなしに自立し手動停止した。
前傾でAngleY増加、両輪の正電圧で前進、前傾→前進／後傾→後退の復元方向も確認済み。
**この派生版のFullモード・位置速度帰還・走行・減速停止は実機未検証。**

## 再使用する経路

2204時代から残る `requestLqrDrive` → 安定待ち → `startPendingLqrDrive` →
距離による減速 → ゼロ速度ブレーキ → 現在位置保持、という経路を復帰させる。
新しい走行制御器や状態機械は追加しない。起動時のモードはAttitudeOnlyのまま。
`g` で Full → AttitudeSpeed → AttitudeDistance → AttitudeOnly を循環選択できる。
稼働中・待機中のモード変更は禁止のまま。AttitudeOnlyでは走行要求と待機ブレーキを
受け付けず、親版の式をそのまま比較できる。走行試験はFullを明示的に選ぶ。

AUTO STARTは静止倒立であり、目標速度0、走行フラグOFF、開始要求なし。
シリアルの `>` / `<` が明示的な走行要求。既存PS4も共通要求入口を使うが、
PS4の入力・脚操作・専用の速度窓／目標傾斜生成等のコードは変更しない。
今回の操作手順はシリアルによる短距離試験に限定する。

## 変更前後の制御式と符号

前進を正とし、xは車輪角度平均[rad]、vは車輪角速度平均[rad/s]、
θはAngleY[deg]、ωはGyroY[deg/s]とする。左右の車体方向係数は＋1、平均係数は各＋0.5。
センサー方向の電気的補正はSimpleFOCに任せ、これらの車体係数とは分離したまま。

親c4ba29bで実行可能だった式:

```text
A = PID_angle(θ − θ0)     P=1
G = PID_gyro(ω)            P=0.08
D = S = 0
LQR_u = test_LQR_u = A + G
右Uq = 左Uq = clip(A + G, ±1 V)
```

親版内に残っていた走行用コードはロックにより未実行で、非AttitudeOnlyの出力変換は
`−(A+G+D+S)`、非PS4の角度誤差は `θ−θ0＋bias` だった。
このまま解除すると姿勢項が自立成功版と逆になり、走行目標傾斜も逆になる。

派生版のFullモード（モードごとの不要項は選択時に除外）:

```text
ev = v_target − v
bias = clip(0.125 * ev, ±0.10 deg)   非PS4の走行中だけ。それ以外は0
θ_target = θ0 + bias                非PS4短距離走行
A = PID_angle(θ − θ_target)         P=1、従来の正の復元作用
G = PID_gyro(ω)                     P=0.08、従来の正の復元作用
D = PID_distance(x0 − x)            P=0.4
S_raw = PID_speed(ev)               P=0.5
S = 状態に応じて選択する直接速度項
LQR_u = test_LQR_u = A + G + D + S  Fullの場合
右Uq = 左Uq = clip(test_LQR_u, ±1 V)
```

- A・G: 自立実績の正の作用を全モードで使う。最後に全項を一括反転する方式は使わない。
- D: 誤差 `x0−x` を維持。前進して位置目標を越えれば負の電圧寄与になる。
  走行中・姿勢だけの回復中は0、回復時の位置項ランプも既存どおり。
- S: 誤差 `v_target−v` を維持。静止目標で前進速度が出れば負の寄与になる。
  既存の走行・減速中の倍率1.25も維持。直接速度項の逆転フラグはNORMALにし、
  無効のままの任意の逆走補助項も同じ速度誤差の符号へ合わせる。
  有効化フラグやゲインは変更せず、補助機能を新たに有効にはしない。
- **非PS4の通常走行中は従来どおり直接速度項OFF**。位置項もOFF。
  正の速度要求は正のbias、すなわち前傾目標を作る。角度誤差ではbiasを引く。
  直立から前傾目標へ変更した直後は、前傾姿勢を作るため一時的に負電圧となり得る。
  「正の速度要求なら毎サンプル必ず正電圧」という制御ではない。
- PS4固有の正の目標傾斜生成と `θ−(θ0+PS4目標傾斜)` は維持。
- 待機ブレーキ: 既存の `clip(S_raw * 0.5, ±0.20 V)` を各輪に使用。
  目標速度0なので前進速度に対して負のブレーキ。AttitudeOnly選択時はOFF。
- 減速停止: 目標速度を0にし、位置目標は現在位置に追従。
  Sは `PID_speed(−v)*1.25` の負帰還を出す。低速安定／ゼロ交差後に現在位置保持へ戻る。
- `e` / 走行異常: 既存のDRIVE_ONLY回復。走行要求を消してA+Gを継続し、
  姿勢安定後の位置項ランプへ戻る。位置・速度項の符号を姿勢項とまとめて逆転しない。

AttitudeSpeedはA+G+S、AttitudeDistanceはA+G+D、AttitudeOnlyは親版同様A+G。
`LQR_u`も選択した式にそろえる。`p`と制御トレースは実際に加算したD/Sを表示し、
未使用の速度PID結果は別の `speed_pid_raw`、直接項は `speed_direct_term` として区別。
`drive_target_tilt` は現在の走行目標傾斜差分[deg]。
表示処理でPIDや制御値を書き換えない。

## 維持する設定・終了条件

- 角度P=1、角速度P=0.08、位置P=0.4、速度P=0.5。I/Dやランプ、速度フィルター設定を含め変更しない。
- 供給／driver範囲8.3 V、アライメント2 V、初期化後のmotor上限1 V。
- CheckedWheelSensor、最新shaft取得、初期化／極対数／通信異常の両輪停止とfaultラッチを維持。
- 起動のアライメントは車輪を動かすが、倒立開始は `t` 後の既存安定判定だけ。
- 走行要求後は先頭500 msで姿勢基準を計測（絶対誤差1°以内）、その基準から0.30°以内、
  gyro 2 deg/s以内、10 ms差分速度の現在値・平均値とも0.15 rad/s以内が200 ms連続で必要。
  開始条件が成立せず5秒経過すると既存の走行中止・姿勢回復へ入る。
- **既存距離値の単位はmではなくrad**。0.03 radから減速、0.05 radで自動ゼロ速度停止。
  半径0.029 mの換算では約0.87 mm／1.45 mm。目標速度±0.30もrad/s（約±8.7 mm/s）。
  数値・単位変換処理は変更せず、この距離を5 cmと解釈しない。
- 既存の移動上限0.70 rad（約20.3 mm）、逆走猶予150 ms、通常逆走0.015 radが120 ms、
  ハード逆走0.03 radが100 ms、駆動中の角度／gyro／速度／飽和の中止条件を維持。
- ゼロ速度停止の完了は、速度のゼロ交差または|v|≦0.08 rad/sが250 ms継続。
- 転倒判定は既存の20°超80 ms／35°以上30 ms・最低3サンプルと不連続除外のまま。
- `.` は減速停止／未開始要求の取消、`e` は走行中止して倒立継続。
  `d` は倒立試験解除・両ドライバー停止。`s` / `0` は倒立解除ではない。
  AS5600異常は両ENを即時LOWにして再起動まで再有効化不可。

## 短距離走行の操作

1. 親PR #11/c4ba29bへ戻せる状態を保持する。電流制限付き8.3 V電源、即時遮断できる
   スイッチを用意し、機体の転倒を受け止められる環境で初期化する。
   起動時のMPU校正中は静止させ、2 Vのアライメントによる車輪回転に備える。
   PS4からの同時入力は行わない。
2. シリアル115200で左右初期化成功を確認。初期値はAttitudeOnly。
   最初の比較確認は `t` → AUTO STARTで親版の自立式を確認し、終了は `d`。
3. `d`後は `u` でゼロ電圧で再有効化。停止状態で `g` を1回送り **FULL** を選択する。
   `p`でモードを確認し、`t`。2秒準備と連続1.5秒安定判定後のAUTO STARTを待つ。
   AUTO STARTだけでは走行しない。まず位置・速度項を含む静止倒立を確認する。
4. 静止倒立中に `>` を1回だけ送る。開始判定が成立すると
   `LQR DRIVE STABLE: starting.` と正のtarget_speedが出る。
   0.03 radから減速し、0.05 radでゼロ速度ブレーキへ入り、
   `LQR DRIVE STOP: position hold engaged` で位置保持に戻ることを確認する。
   開始条件タイムアウト、逆走、駆動異常が出たら追加要求を重ねない。
5. 前進試験を終了して `d`。必要なら機体位置を安全に戻す。
   `u` →（FULL選択を確認）`t` → AUTO START後、`<` を1回送り後退も同様に確認する。
6. 途中の通常停止は `.`。開始待ちなら取消、走行中ならゼロ速度停止になる。
   走行だけを直ちに中止するには `e`（倒立は継続）。倒立自体も終了するには `d`。
   応答しない／想定外の挙動は物理的にモーター電源を遮断する。
7. 比較モードへ戻すには `d`、停止状態で `g` をFull→AttitudeSpeed→AttitudeDistance→
   **AttitudeOnly**まで3回送る。`u` → `t`で親版と同じA+Gの式になる。
   バイナリ自体を成功版へ戻す場合は、保持したPR #11/c4ba29bを使用する。

ゲイン・閾値の調整、接地での安定性の保証、実機書き込み・マージはこの変更に含まない。
短距離走行・静止Full・減速停止はいずれも**実機未検証**。

## 転倒後のWebログ取得

USBなしのWeb試験で、手を離した直後に前進・転倒し、停止後の件数とCSVが0件だった。
TILT_STOPがシリアル出力直後にトレースを消去していたため、以下を修正した。
この変更は転倒原因を調整するものではなく、停止後に原因を調査するためのログ保持である。
PID・制御式・電圧・転倒判定の閾値は変更していない。

- 転倒判定後、EN遮断・指令/PWMのゼロ化を先に実行し、その後にシリアルへ出力する。
- 速度・ループ時間・制御の各トレースを停止後もRAMに保持する。
  制御トレースには出力0の停止サンプルを加える。停止後の通常ループでは追記しない。
- Web画面に `Last stop reason: TILT_STOP` と件数を表示する。
  通常の手動停止は `MANUAL_STOP`、車輪通信異常は `WHEEL_FAULT`。
  停止ボタンの再押下、停止状態で拒否された開始では転倒理由を上書きしない。
- 転倒後はWebのVelocity／Loop Timing／LQR Control Traceリンクから保存する。
  同じCSVを繰り返し取得してもログは消去されない。
- 消去は次のSTARTが開始条件を通って受理された時点。
  安定待ちの終わり（AUTO START）では消去しない。開始拒否時も保持する。
  再起動・電源断ではRAMのログは失われるため、先にCSVを保存する。
- Loop Timingは従来の遅延条件を満たした時だけ採取するため、0件の場合もある。
  採取周期・件数上限・遅延条件は変更していない。

`python3 tests/drive_host/run.py` に、実停止処理・Web/CSVハンドラーを使った
転倒後保持、停止前の遮断順、反復取得、停止理由、拒否時保持、次回開始時消去の回帰を追加。
ログ保持修正後のUSBなし実機試験は未実施。マージ・実機書き込みは行わない。
