# 初期化直後の初回自動倒立

> 最新の保存校正・転倒復帰仕様は [保存校正と転倒復帰](persisted-calibration-and-fall-recovery.md) を参照。
> 通常起動の校正走査は廃止。転倒停止だけは直立1.5秒で自動復帰する仕様へ変更。
> 以下は即時開始導入時の履歴であり、転倒後再始動禁止・毎回校正の説明は現在の仕様ではない。


基準先頭f707d90。ceafc72の右−1／左＋1を保持。
**起動後、必須初期化と最初の正常な測定更新が完了した周期に倒立制御を開始する。**
USB u／tやPS4の開始操作は不要。±2°の開始待ち、1500 ms保持、2秒準備、
起動姿勢からの基準角自動取得は行わない。

## 初期化・目標と原点

既存のWeb必須機能、IMU初期化・校正IO成功、両輪FOC／PP合格、
ドライバー・センサー正常が前提。追加I2Cは行わず通常ループで取得した最新値を使用する。
姿勢・角速度・車輪位置／速度が有限で測定が新しいことを確認する。
初期化前／校正中／測定未取得では開始しない。校正失敗・IMU読取り異常等では自動意図を解除。

既存の開始リセット経路を共用し、起動専用分岐では次の値を直接設定する。

- 姿勢目標 `angle_zeropoint=0.0 deg`。その場の傾きを学習しない。
- 車輪位置原点 `distance_zeropoint=LQR_distance`（右−0.5／左＋0.5で合成した位置）。
- 走行安全の起点も開始時の同じ位置。前進要求・旋回要求はリセット済みの0。
- 基準有効化と倒立armedを同周期で設定。既存の制御計算・左右出力・安全判定へ進む。

既存の初期モードATTITUDE_ONLYを維持。PID、制御項の符号、方向係数、
FOC設定・電圧・極対数・フィルター・転倒／異常／明示停止条件を変更しない。
起動角の許容待ちを撤去したため、大きく傾いていても制御開始へ進み得る。
転倒閾値と連続確認時間を短縮したわけではなく、従来の判定をそのまま通る。

初回のみの意図であり、明示停止・転倒・異常後は自動再始動しない。
uだけで自動開始意図を復活させない。PS4／シリアルの手動再開始は既存の経路を維持し、
その従来の準備・安定保持・基準取得は今回変更していない。
再起動した場合は新たな初回として自動開始が有効。

## Web・資源

姿勢と最終指令電圧は停止／待機状態でも配信する。測定が継続できない場合は、
既存の実測時刻・有効性・理由表示で無効化し、古い値を現在値に見せない。
Web接続／配信を新しい開始条件にしない。既存Web起動前提は維持する。
data・通信方式・期限・WDT対策・スタック・FIFO・長期履歴なしの方針は変更しない。

## 更新・実機確認（未実施）

**ファーム更新が必要。正常初期化後すぐ両輪が駆動し得るため、機体を確実に保持する。**
dataは無変更なので、直前版の画面が書込み済みならLittleFS更新は不要。

```sh
pio run -e esp32dev
# 利用者が保持・対象ポートを確認して実施。エージェントは未実施。
pio run -e esp32dev -t upload --upload-port PORT
```

校正中は機体を静止させ、FOCアライメントの従来の動作にも対応できる状態で起動。
両輪accepted=1／PP合格後、BOOT AUTO: BALANCINGと固定reference=0を確認する。
起動した姿勢へ目標が移っていないこと、開始時車輪位置が原点になっていることをWeb等で確認。
中止はUSB d／PS4×。停止後に姿勢を戻しても自動再始動しないことを確認する。

## 検証範囲

ホストの実制御関数で、初期化／FOC未完了・校正中／未完了は未開始、
校正／IMU／センサー異常は意図解除、正常後は時間を進めず1回の処理で開始することを確認。
5°・3 deg/s・速度1 rad/sで従来の開始待ちを通らず、角度目標0°、位置原点4.25 radに設定。
姿勢誤差による出力、停止／転倒／異常後の再始動なし、PS4手動再開始と停止、
左右方向・速度・旋回・減速の回帰、開始後のWeb姿勢・目標・指令値を確認。
実機の即時開始、姿勢復帰・静止倒立、停止・再開始、通電方向・走行・旋回、
Wi-Fi併用での制御周期は未検証。ビルド／ホスト成功を実機成功とは扱わない。
