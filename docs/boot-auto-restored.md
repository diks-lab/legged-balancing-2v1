# 起動時自動倒立の再有効化

基準先頭ceafc72。右−1／左＋1の実測方向修正を保持して自動開始を再有効化。
**更新後はu・tを送らなくても、正常初期化・許容姿勢・基準取得後に両輪が駆動する。**

Web必須機能、校正IO成功、両輪FOC／PP合格、センサー正常が前提。
既存の重力基準0°から±2°、角速度2 deg/s以下、車輪速度0.8 rad/s以下を
1500 ms保持後、既存Start経路へ進む。続いて既存2秒準備＋1500 ms安定保持で
基準角／位置を取得し、有効化後にだけ倒立開始。任意の傾いた起動姿勢は無条件に基準登録しない。
開始モードは従来のATTITUDE_ONLY。PID、FOC、方向係数、開始／転倒閾値を変更しない。

初回だけの意図であり、明示停止・転倒・センサー異常後は解除され、
uでドライバーを再有効化しても自動再始動しない。PS4／シリアルの既存手動再開始を維持。
新しく再起動した場合は、再び自動開始が有効となる。
Web／PS4接続を新しい開始条件にしない。従来のWeb起動前提は維持。

Webの姿勢角は停止・開始待ちでも既存の実測値を更新し、指令電圧は実際の最終指令を表示。
制御の開始待ちで隠さない。センサー未取得・異常・古い値は既存の鮮度処理で無効化する。
今回dataは無変更、ファーム更新が必要。LittleFSは直前版が入っていれば更新不要。

```sh
pio run -e esp32dev
# 利用者が保持・ポートを確認して実施。エージェントは実施しない:
pio run -e esp32dev -t upload --upload-port PORT
```

機体を確実に保持し、MPU校正中は静止、FOCの既存回転にも対応できる状態で起動する。
BOOT AUTO: ENABLED、両輪のaccepted=1／PP合格を確認。
許容姿勢へ入れて基準取得後の倒立開始を確認する。中止はUSB d／PS4×。
明示停止後は姿勢を戻しても自動再始動しないことを確認する。

ホストでは、正常初期化・基準有効化後に入力なしで開始し、未初期化・校正失敗・
許容姿勢外で開始しないこと、停止／転倒／異常後の再始動なしを実制御関数で検証。
開始待ち中の姿勢と指令ゼロ表示、右負／左正の位置・速度・出力、PS4処理も回帰。
実機の自動開始、基準取得・静止倒立・停止・再開始、通電方向と走行は未検証。
ビルド成功を実機成功とは扱わない。マージ・実機書込みなし。
